# formula_fingerprint

`formula_fingerprint` writes a fingerprint derived from the molecular formula. It is a
very cheap fingerprint to generate and to compare, which makes it useful for fast
approximate searches, particularly with Tversky similarity.

```
formula_fingerprint molecules.smi > molecules.formula.gfp
```

The output is a TDT file with `$SMI<`, `PCN<` and fingerprint records that can be used
with the usual `gfp_` tools, or read from Python with `GFPList.from_file()`.

## What is counted
The fingerprint has 18 counted positions: carbon, nitrogen, oxygen and sulphur (each
counted separately when aromatic), fluorine, phosphorus, chlorine, bromine, iodine,
other elements, the number of atoms bearing a hydrogen (separately for heteroatoms,
aromatic carbons and other carbons), and the number of ring atoms.

With `-L s,d` the counts are scaled nonlinearly, `s * log(count + 1) / log(d)`, which
emphasises differences between small counts. The change from zero to one sulphur atom
matters much more than the change from 20 to 21 carbon atoms. `-L 200,41` is
suggested.

## Sparse and fixed counted forms
The tag prefix chooses the kind of fingerprint written, so the tag and the data always
agree:

| Tag | Fingerprint |
| --- | --- |
| `FCFML<` (default), any tag starting `FC` | fixed size counted |
| `NCFML<`, any tag starting `NC` | sparse counted |
| `FCFMLNH<` (default with `-H`) | fixed size counted, without the hydrogen counts |

Any other prefix is an error. The fixed size counted form is the default because it is
the form generated by the Python `GFP.formula()`, so a file written by this tool can be
searched with a query fingerprint generated in Python. The sparse form has a different
tag and cannot be compared with the Python fingerprints. The command line tools such
as `gfp_lnearneighbours`, including its `-V` Tversky options, handle both forms.

The default log scaling is `-L 200,41`, the same as Python. Use `-L none` for raw
counts. The tag does not record the scaling, so using a different `-L` with a `FC`
tag produces fingerprints that cannot be compared with Python, and a warning is issued.

```python
from lillymol import GFP, GFPContext, GFPList, MolFromSmiles, Tversky

ctx = GFPContext.from_specs([GFP.formula()])
gfp = GFPList.from_file("molecules.formula.gfp")
query = ctx.fingerprint(MolFromSmiles("CC(=O)Nc1ccc(O)cc1 query"))
hits = gfp.nearest_neighbours(query, 10, tversky=Tversky(query=2, candidate=0))
```

## Without the hydrogen counts
Three of the counts are of atoms bearing hydrogens (on heteroatoms, on aromatic carbons
and on other carbons). A substructure query written as a fragment has hydrogens on atoms
that are substituted in a molecule that contains it. For approximate substructure
searching, where a molecule must have at least the counts of the query, those counts can
therefore prevent a match. With `-H` they are not counted, and the fixed counted tag
becomes `FCFMLNH<`, the same as Python `GFP.formula(hydrogens=False)`.

```
formula_fingerprint -H molecules.smi > molecules.formula_nh.gfp
```

The tag for a fingerprint without the hydrogen counts is different, so fingerprints
with and without them cannot be compared. As a consequence, `-H` with the tag `FCFML`,
and the tag `FCFMLNH` without `-H`, are errors.

This is not a selective filter. It is useful because it is very fast, so that more
precise measures need only be applied to the molecules it finds. See
[Python Tversky searching](/docs/python/LillyMolPython.md#approximate-substructure-searching-and-pre-filtering)
for measurements.

## Options
```
 -J <tag>       tag to use, the prefix selects the kind of fingerprint (default FCFML)
 -H             do not count atoms bearing hydrogens, the default tag becomes FCFMLNH
 -L s,d         log scaling of counts (default 200,41), or -L none for raw counts
 -f             function as a TDT filter
 -i ...         standard input control options
 -E ....        standard Element control options
 -A ....        standard Aromaticity control options
 -v             verbose output
```

## gfp_make
`gfp_make.sh -FORMULA file.smi` writes the fixed size counted form (`FCFML<`), the same
as this tool. `gfp_make.sh -FORMULA,sparse file.smi` writes the sparse form (`NCFML<`).
`gfp_make.sh -FORMULA,nohydrogen file.smi` writes the form without the hydrogen counts
(`FCFMLNH<`). The qualifiers can be combined, for example `-FORMULA,sparse,nohydrogen`.
`-FORMULA,fixedcounted` is accepted as an explicit synonym for the default. Other
options for `formula_fingerprint` can be passed with a `-formula ... -formula` group.

Earlier versions of `gfp_make` wrote the sparse form (`NCFML<`) for `-FORMULA`. Files
written then are still valid, but gfp tools need the same fingerprint tags on both sides
of a comparison, so they must be regenerated, or regenerated with `-FORMULA,sparse`, to
be compared with files made now. `gfp_to_svm_lite_v3` handles both forms, treating each
position of a fixed size counted fingerprint as a counted feature.

See also the [Python Tversky searching](/docs/python/LillyMolPython.md#tversky-searching)
documentation.
