# Exploring an SAR series

You have a set of molecules with a measured activity and want to know what is going on:
which properties, functional groups or fragments go with high or low activity? Three
LillyMol tools answer that from complementary angles. Each reads the same two inputs and
writes a self-contained HTML report you can pass to a colleague.

| Tool | Question | What is examined | Detailed help |
|---|---|---|---|
| `descriptor_ranking.sh` | Which computed *properties* vary with activity? | About 250 `iwdescr` descriptors | [descriptor_ranking](../Molecule_Tools/descriptor_ranking.md) |
| `substructure_exploration.sh` | Do molecules with a *known feature* differ in activity? | A catalogue of 85 functional groups, rings and ring systems, or your own queries | [substructure_exploration](../Molecule_Tools/substructure_exploration.md) |
| `dicer_fragment_activity` | Which *fragments found in your molecules* go with activity? | Fragments generated by `dicer` | [dicer_fragment_activity](../Molecule_Tools/dicer_fragment_activity.md) |

The two fragment-based tools use the same report and differ in where the features come
from. `substructure_exploration` asks about features chosen in advance, and
`dicer_fragment_activity` finds them in your data, so it can turn up something nobody
thought to ask about. The descriptor tool is about continuous properties such as size,
lipophilicity and polarity, rather than the presence or absence of a feature.

## Inputs

Both inputs are shared by all three tools.

- **Molecules**: a SMILES file. The identifier is the first token of the name.
- **Activity**: a file with a header, then identifier and activity columns.

```text
ID activity
mol1 6.2
mol2 7.1
```

Use an activity on a scale where a difference means something, such as pIC50, rather
than raw IC50. `descriptor_ranking.sh` has `--transform neglog10` for that.

Give the tools the same prepared SMILES file. They differ in how much chemical
standardisation they apply: `substructure_exploration` standardises by default
(`--no-standardize` turns this off), `iwdescr.sh` applies its own, and `dicer` works on
the structures as supplied. Preparing the file once, for example with `fileconv`, keeps
the three reports describing the same molecules.

## Running all three

```shell
# Properties
iwdescr.sh molecules.smi > molecules.w
descriptor_ranking.sh -A activity.txt -o descriptors.html molecules.w

# Known features
substructure_exploration.sh analyse -A activity.txt molecules.smi \
  -o substructure.json --html substructure.html

# Fragments found in the data
dicer -k 3 -I 1 -B serialized_proto -S diced.dat molecules.smi
dicer_fragment_activity -A activity.txt -tfdata -support 10 -json fragments.json diced.dat
dicer_fragment_activity_html.sh fragments.json --top_n 100 -o fragments.html
```

The tools are independent, and run in any order or alone. Their dependencies differ:

| Tool | Needs |
|---|---|
| `descriptor_ranking.sh` | Python with numpy, pandas, scipy, scikit-learn, matplotlib. No LillyMol bindings. |
| `substructure_exploration.sh` | The staged LillyMol python bindings and `protobuf`. RDKit for structure images (optional). |
| `dicer_fragment_activity` | The compiled `dicer` tools. The HTML step needs only the Python standard library; RDKit and the bindings are optional, for depiction and highlighting. |

## Reading the reports together

I'd go in this order.

1. **Descriptors first.** The strongest and most pervasive signals in an SAR series are
   often general properties, such as size or lipophilicity. The descriptor report shows
   whether one dominates, and it clusters redundant descriptors so you see each
   independent effect once.
2. **Then functional groups**, with that in mind. If activity rises with size, then any
   group that makes molecules bigger will look favourable.
3. **Then fragments.** These can identify specific building blocks or sub-series, and are
   the most specific and the most prone to marking one series of near-identical analogues.

The statistics are different in each tool and their numbers are **not comparable**. The
feature tools report the difference in mean and median activity between molecules that
have the feature and those that do not. The descriptor tool reports η² and random-forest
importance, which are shares of variance. Compare the *shape* of what each shows, not its size.

All three share the same caveats:

- The results are associations within this dataset, not causes.
- Features are correlated with each other, so a high-ranking feature may be a proxy for
  another. The descriptor tool collapses correlated descriptors explicitly. Fragments and
  functional groups overlap and are not collapsed.
- Chemical series are confounded with everything: a feature found only in one series
  inherits that series' activity.
- A group with few molecules can look dramatic by chance. Look at the molecule counts
  alongside the effect.

See each tool's help file (linked above) for options, input details and how the
statistics are calculated.
